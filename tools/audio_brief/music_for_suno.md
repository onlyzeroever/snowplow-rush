# Snowplow Rush music: made in Suno

Fish Audio doesn't make music, so the 5 tracks are made in Suno. Suno gives commercial rights only for songs made on a paid plan (Pro or Premier) and downloaded while subscribed, so use a paid plan the whole time.

## How to make each track

1. Turn on **Instrumental**.
2. Paste the style prompt below exactly as written. No lyrics, no title words.
3. Make `music_job` first. Listen, and if it isn't fun and cozy, make it again before doing the others. The other four use the same instruments and key, so they sound like one soundtrack.
4. Make 2 versions of each track, and download every version as WAV.
5. Name each file `<name>_1.wav` and `<name>_2.wav`, e.g. `music_job_1.wav`, and attach them in the chat with Claude.

Don't worry about length or endings. I cut each track into a seamless loop (about 70–90 s) and level it under the sound effects.
